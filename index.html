☁ Bulut — barcha telefonlar

Bir marta bepul Firebase ochasiz. Keyin bir xil login/parol telefon, planshet, kompyuterda ishlaydi.

  1. console.firebase.google.com oching (Google akkaunt)
  2. Add project → nom: IdealFerma → Create
  3. Chapda Build → Authentication → Get started → Email/Password → Enable → Save
  4. Chapda Build → Realtime Database → Create Database → Start in test mode → Enable
  5. Chapda ⚙️ Project settings → pastga Your apps → Web (</>) → nom: ferma → Register
  6. firebaseConfig kodini nusxa oling (apiKey, authDomain…)

databaseURL bo‘lmasa Realtime Database URL ni qo‘shing (masalan https://PROJECT-id-default-rtdb.firebaseio.com)
